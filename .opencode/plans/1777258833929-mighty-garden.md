# pp2 Redundancy Analysis and Optimization Plan

## Issues Identified

1. **Significant code duplication** between `pp2.ps1` and `module\pp2\pp2.psm1`
   - Both files contain nearly identical implementations of the main `pp2` function
   - Both contain the same parameter definitions, action handling, and helper functions
   - This creates maintenance burden and potential inconsistencies

2. **Library files** (`lib\pp2-*.ps1`) are properly modularized with no obvious duplication

3. **Installation files** serve different purposes:
   - `install.ps1`: Full interactive installation script
   - `winget\manifest.yaml`: Template for Winget package submission (not functional)
   - No redundancy between these

## Recommended Solution

Refactor the project structure to eliminate duplication while maintaining both usage patterns:
1. Direct script execution (`pp2.ps1`)
2. PowerShell module import (`Import-Module pp2`)

### Changes to Make

#### 1. Simplify `pp2.ps1` (CLI Entry Point)
Transform `pp2.ps1` into a thin wrapper that:
- Imports the pp2 module
- Calls the main `pp2` function with passed arguments
- Handles basic error reporting

#### 2. Keep `module\pp2\pp2.psm1` as the Core Implementation
Maintain all functionality in the module:
- All parameter definitions
- All action handling (status, start, stop, etc.)
- All helper functions
- Function exports

#### 3. Update `module\pp2\pp2.psd1` if Needed
Ensure the module manifest accurately reflects the exported functions.

## Verification Steps

1. After changes, test direct execution:
   - `.\pp2.ps1 help`
   - `.\pp2.ps1 status`
   - `.\pp2.ps1 start <service>`

2. Test module import:
   - `Import-Module .\module\pp2\pp2.psd1`
   - `pp2 help`
   - `pp2 status`

3. Verify installed version works:
   - After running install.ps1, test `pp2 help` in new terminal

## Benefits

- **Eliminates duplication**: Single source of truth for all functionality
- **Maintains compatibility**: Both direct execution and module import work
- **Simplifies maintenance**: Changes only needed in one place
- **Reduces potential for inconsistencies**: No risk of pp2.ps1 and pp2.psm1 diverging
